## Reddit

### Title

I built DevToolbox: 37 local-first developer tools that run in the browser

### Body

I’ve been building DevToolbox as a browser-based workspace for common developer utilities.

The project now has 37 tools across developer/data, image, PDF, conversion and general utilities. The main difference from many online tool sites is that supported processing happens locally in the browser.

v4.1 adds Workspace Collections, Smart File Inspector and a Package.json Analyzer. Files can also move between compatible tools through the local Workspace.

There is no account system, analytics backend or automatic cloud upload.
